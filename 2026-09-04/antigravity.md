# Antigravity 변경사항

## GUI App

- 버전: `2.12.0` (이전: `2.11.0`, 2026-09-02 공개)
- 응답 일부를 골라 후속 프롬프트 인용으로 넣을 수 있고, 유료 사용자는 다중 에이전트 추론 파이프라인인 `/boost`를 쓸 수 있습니다.
- 일반 설정이 어떤 프로젝트가 설정을 덮어썼는지 보여 주고 그 프로젝트 설정으로 바로 가며, 덮어쓰기가 있으면 설정 창이 활성 프로젝트 설정을 엽니다.
- 터미널 분할 레이아웃이 창 다시 로드 뒤에도 남고, 사이드 질문 패널에 앞·뒤 이동이 있으며, 받아쓰기 중에도 보내기 버튼으로 메시지를 보낼 수 있습니다.
- 오디오 드래그 앤 드롭, 느린 네트워크 중 턴 도중 인증 오류, 권한 프롬프트의 구체적 동작 설명, 나란히 돌던 서브에이전트가 진행 보고 때 사라지던 문제, 실패한 커스텀 훅이 세션을 끝내던 문제를 고쳤습니다.
- 공식 페이지는 점진 배포를 안내하므로 실제 업데이트 도달까지 며칠 걸릴 수 있습니다.

## IDE App

- 버전: `2.5.5`
- 이전 기록 이후 새 IDE 버전은 확인되지 않았습니다.

## CLI App

- 제품 탭: `2.0`, 바이너리: `1.1.25` (이전: `1.1.23`, 2026-09-03 공개)
- `/resume` 선택기에 워크스페이스별 묶음 보기(Ctrl+F로 전환)를 넣었고, `GEMINI_API_KEY` 사용자 모델 목록에 Gemini 3.8 Flash를 추가했습니다.
- Markdown 커스텀 에이전트가 기본으로 주변 스킬·규칙·서브에이전트를 물려받습니다.
- `1.1.24`: `/mcp` 패널 화살표 탐색, `mcp_config.json` 주석·후행 쉼표, 헤드리스 스트림이 종료 때 닫히지 않던 문제, 중복 에이전트 목록, 삭제된 작업 디렉터리 기동 실패를 고쳤습니다.
- 1024자를 넘는 MCP OAuth 코드, Windows 스킬 경로 구분자, `/boost` 워커 도구, 궤적 종료 뒤 nil 포인터 크래시를 고쳤습니다.
