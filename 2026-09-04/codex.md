# Codex 변경사항

## GUI App

- 버전: `26.727`
- 이전 기록 이후 새 GUI 앱 버전은 확인되지 않았습니다.

## CLI App

- 버전: `0.153.0` (이전: `0.152.1`, 2026-09-03 공개)
- Vim 초안에서 `u` 실행 취소와 `Ctrl+R` 다시 실행을 지원하고, 붙여넣은 내용과 첨부까지 유지합니다.
- 플러그인 CLI가 원격 마켓플레이스에서 플러그인을 나열·설치·삭제할 수 있고, `tui.auto_recap = false`로 자동 요약을 끄면서 `/recap`은 남깁니다.
- TUI 히스토리에 전체 패치, 백그라운드 터미널 입력, 완료된 명령을 각각 보여 주고, Plus·Team은 약 5시간 사용 구간에서 한도의 절반이 남기 전에 경고합니다.
- 앱 서버 연결이 끊겨도 TUI가 초안·트랜스크립트를 유지한 채 다시 붙고, Full Access는 확인만 하는 작업의 Guardian 리뷰를 건너뜁니다.
- Guardian 리뷰 기록이 압축·재시작·포크 뒤에도 남고, 기억된 MCP 도구 승인은 선택한 앱 계정에 묶입니다.
- 기본 꺼진 `features.context_management.experimental_mode`를 넣었습니다. 대상 ChatGPT Plus·Pro·Pro Lite 세션에서 토큰 예산 컨텍스트와 `new_context` 도구를 켭니다.
