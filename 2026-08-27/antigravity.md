# Antigravity 변경사항

## GUI App

- 버전: `2.10.0`
- 이전 기록 이후 새 GUI 앱 버전은 확인되지 않았습니다.

## IDE App

- 버전: `2.5.5`
- 이전 기록 이후 새 IDE 버전은 확인되지 않았습니다.

## CLI App

- 제품 탭: `2.0`, 바이너리: `1.1.21` (이전 바이너리: `1.1.20`, 2026-08-25 공개)
- `/voice` 받아쓰기와 SSH 마이크 전달 `mic-serve`를 넣고, 상태줄에 세션 비용(`cost`)을 노출합니다.
- 에이전트 코드 검색에 내장 `ripgrep`을 쓰고, always-proceed는 MCP 도구·페이지 읽기를 자동 승인합니다. 스크립트 러너 허용은 스크립트 이름 단위입니다.
- 대화 제목을 생성 시 자동으로 만들고, CJK 등 비ASCII 편집이 깨지거나 잘못된 UTF-8로 세션이 멈추던 문제를 고쳤습니다.
- 성공한 파일 쓰기를 실패로 보고하던 문제와, 명시 스킬·플러그인 경로가 자동 발견보다 우선하지 않던 문제를 수정했습니다.
- 공식 페이지는 점진 배포를 안내하므로 실제 업데이트 도달까지 며칠 걸릴 수 있습니다.
