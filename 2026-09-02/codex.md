## CLI App

- 버전: `0.152.0` (이전: `0.151.0`)
- Vim 초안에서 `/`·`?` 검색과 n/N 이동, 한도 배너의 사용량·크레딧·플랜 액션, Bedrock 포함 자격증명 갱신 진행 표시를 넣었습니다.
- MCP 서버 이름에 `:`, `@`, `/`, `.`를 허용하고, 도구별 `output_token_limit`과 1시간을 넘는 스레드/셸 타임아웃을 설정할 수 있습니다.
- 플래닝 도구는 기본 꺼지고 `tools.update_plan.enabled = true`로 켭니다. 플러그인 추천은 시작 시 미리 불러옵니다.
- Guardian 리뷰가 긴 메시지·지시·권한을 압축 뒤에도 남기고, 재개 스레드는 저장 cwd를 복원하며, Windows Store PowerShell 샌드박스와 클라우드 작업의 비신뢰 URL을 고쳤습니다.
