# Antigravity 변경사항

## GUI App

- 버전: `2.10.0` (이전: `2.9.1`, 2026-08-20 공개)
- 사이드바에 내장 터미널(Ctrl/Cmd + `)을 넣었고, Review 창에서 Git 작업 트리 diff·스테이징·커밋을 할 수 있습니다.
- MP3·WAV·M4A 등 오디오(최대 20MB) 첨부와 이미지 영역 선택 댓글, MCP·커스텀 도구 실행의 구조화된 미리보기를 추가했습니다.
- URL 아티팩트가 로컬 개발 서버와 Google Docs·Sheets·Slides·Drive를 앱 안 미리보기로 열고, @-멘션 파일 검색은 오타를 허용합니다.
- 슬래시 메뉴가 커스텀 에이전트에 없는 명령을 보여 주던 문제, `/goal` 진행 표시 누락, 이미지 첨부 유실, 비즈니스 로그인 라이선스 오류 화면을 고쳤습니다.

## IDE App

- 버전: `2.5.5`
- 이전 기록 이후 새 IDE 버전은 확인되지 않았습니다.

## CLI App

- 제품 탭: `2.0`, 바이너리: `1.1.20` (이전 바이너리: `1.1.17`, 2026-08-20 공개)
- `SKILL.md`의 `metadata.icon` 이모지를 `/skills`·슬래시 완성에서 보여 주고, `@` 완성에 빈 디렉터리를 넣으며, 기본 검토 모드에서 워크스페이스 읽기는 자동 허용합니다.
- `--project`에 프로젝트 이름을 받고, `@` 완성은 오타를 허용하며, `--remote-control`은 기본 포트가 쓰이면 빈 포트에 붙습니다.
- print 모드의 무해한 도구 오류를 치명으로 보던 문제, 인식 못 한 `settings.json`을 덮어쓰던 문제, `/skills` 등이 내장 커스터마이즈를 못 찾던 문제를 고쳤습니다.
- 공식 페이지는 점진 배포를 안내하므로 실제 업데이트 도달까지 며칠 걸릴 수 있습니다.
